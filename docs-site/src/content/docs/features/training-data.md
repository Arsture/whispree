---
title: 학습 데이터 모으기
description: 받아쓰기 기록을 내 Mac에 쌓아 두고, 필요할 때 zip으로 내보내기.
---

받아쓰기 한 건마다 녹음, 인식 결과, AI 교정 결과, 붙여넣은 뒤 고친 내용을 내 Mac에 저장합니다. 나중에 STT나 교정 모델을 내 말투에 맞게 학습시킬 때 씁니다. 어디로도 전송되지 않습니다.

## 켜는 법

설정 → 일반 → **학습 데이터**에서 **학습 데이터 모으기**를 켭니다. 기본값은 꺼짐입니다.

## 저장하는 것

| 항목 | 내용 |
| --- | --- |
| 녹음 | 원본 오디오(FLAC) |
| 인식 결과 | STT 엔진·모델, 인식된 원문, 걸린 시간 |
| AI 교정 | 프로바이더·모델, 사용한 프롬프트, 교정 결과 또는 실패 사유 |
| 붙여넣기 | 붙여넣은 텍스트, 대상 앱 |
| 붙여넣은 뒤 수정 | 60초 동안 입력창 내용이 바뀐 기록, Enter·Esc·Cmd+Z 시점, 마지막 내용 |
| 화면 | 녹음 중 찍은 스크린샷(화면 컨텍스트를 켠 경우) |
| Quick Fix | 고치기 전후 텍스트 |

비밀번호 입력칸은 읽지 않습니다. 키 입력 자체도 기록하지 않습니다(Enter·Esc·Cmd+Z만 시점을 남깁니다).

## 저장 위치

기본 위치는 `~/.whispree/dataset/`입니다. 앱 밖에 있어서 업데이트하거나 다시 설치해도 남아 있습니다. 설정에서 다른 폴더로 바꿀 수 있습니다.

## 내보내기

**데이터 내보내기**를 누르면 zip 파일 하나로 묶습니다. 기본으로는 녹음과 텍스트 기록만 들어갑니다. **스크린샷과 입력창 기록 포함**을 켜야 스크린샷과 입력창 내용도 들어갑니다. 내 Mac에 저장된 원본은 그대로 남습니다.

:::caution
일부 앱(Electron 앱, 일부 웹 페이지)은 입력창 내용을 읽을 수 없어서 붙여넣은 뒤 수정 기록이 남지 않습니다. 터미널은 화면 전체가 읽혀서 커서 주변만 잘라 저장합니다.
:::
